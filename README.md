# CoolCompiler

A Turing-complete language pipeline built from the ground up, designed to explore the internals of compiler theory, language design, and architectural patterns.

## 🚀 The Vision
`CoolCompiler` is a journey from raw strings to executable logic. The goal is to move beyond high-level frameworks and master "Engineering at the Source."

## 🏗️ Architectural Pipeline
The compiler follows a classic linear pipeline, ensuring a strict **Separation of Concerns (SoC)**:

1. **Lexical Analysis (Lexer):** Converts raw source code into a stream of meaningful Tokens.
2. **Syntax Analysis (Parser):** Transforms tokens into an **Abstract Syntax Tree (AST)** using Recursive Descent.
3. **Execution (Interpreter):** Evaluates the AST using the **Visitor Pattern** to manage state and logic.

## 🛠️ Features
- **Math Engine:** Handles operator precedence and complex expressions.
- **Variables & State:** Supports assignment and retrieval via a Symbol Table.
- **Control Flow:** `if/else` logic with lazy evaluation of branches.
- **Functions:** Scoped function definitions with a local call stack.
